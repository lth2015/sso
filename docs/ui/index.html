可信认证域 · 交互示意

统一身份登录

应用将通过顶层跳转进入认证域；此处只演示流程，不收集密码。

  1. 证明身份：密码与 MFA，或复用有效中央会话
  2. 选择有资格的租户
  3. 确认应用与授权范围
  4. 返回应用，由 BFF 建立会话
租户切换会发起新的授权交易，不能覆盖旧 token 的租户。
