# User 审计客户端：下一切片约束（尚未实施）

在 0.18 协议观察交付后，补齐外部服务读取受控审计批次的 Go 客户端/本地 CLI，复用现有 User API，不增加管理权限或伪造身份。此处保留实施前约束；当前实现与验收分别见 ../user-audit-client.md、../validation.md。

- 仅使用调用者已经通过真实 OAuth code+PKCE 获取的 User Bearer；不接收 Cookie、M2M SK 或任意授权头，不实现身份绕过或替代可信 SSO 登录。User 与机器身份 SDK 保持明确用途。
- 可信代码配置 HTTPS 原点，当前本地仅显式允许既有固定 API 回环入口；固定路径、受控超时/大小、无重定向/Cookie、请求取消和失败关闭，不让请求参数选择主机。
- 管理/机器批次使用冻结、可复用类型，校验固定字段/namespace/kind/数量/游标/时间；不保存成功授权缓存、不自动继续分页或重发；未知/秘密字段和未授权/失效响应不能变成正常数据。
- CLI 从受限 stdin JSON 读取 Bearer 与批次参数，不把 token 放入 argv、环境、文件、日志或错误；只输出通过校验的一个授权批次。stdout 的受控身份标识属于调用者审计数据，工具不暗中持久化。
- 模拟 HTTP/TLS/畸形响应/取消与真实 Hydra/User/Bearer/审计委托/即时 deny/scope/租户/机器 realm 分开验收。公开源码/示例、OpenAPI/手册与离线可编译文档包同步，示例不包含私有输入或凭证。

先完成 0.18 回归、导出、演示保护和主干推送再实施；不更改 CI/GCP/部署或周五保留版，不宣称 marketstars 已联调。
