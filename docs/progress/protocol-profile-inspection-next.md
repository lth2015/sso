# 协议登记只读核对：下一切片约束（尚未实施）

在 0.17 邀请更新交付后，完善自有公开客户端与机器凭证的排障体验。当前显式 reconcile/cleanup 会按既有规则创建、激活或清理；新增能力只读比较受控登记字段，不替代周期补偿 worker，也不执行协议写入。

- 仅当前 active owner 可检查自己空间/自有应用下的指定 managed client 或 machine credential，沿用 User platform:read、主库 roles.manage/版本与固定私有 Admin 目标。机器 Bearer、委托审计/邀请权限、共享应用/其他空间不能获得此能力。
- 先读取合法资源/不可变 profile，再在有界超时内 GET 协议登记，最后主库重查当前资格/资源版本。远程等待期间不持有租户锁；失权拒绝、资源修订改变返回受控冲突，不把早先资格作为授权缓存。只读请求不写登记、权限、审计或 outbox。
- 返回 matching/absent/conflict 的受控观察、固定枚举的差异字段名、资源版本及观察/主库复查时间；绝不返回 Admin 原文、字段实际值、SK/hash/registration token 或任意 metadata。错误固定化，依赖不可用返回 503，不伪装成功。
- matching 仅表示已列出的非秘密字段一致，不证明 SK、JWT 或端到端业务可用，也不改变 pending/active/revoked/expired 的本地状态。未知/遗失 SK 仍须撤销/清理后重建；只读核对不得恢复秘密或激活 pending。协议不一致对象仍不能被收养/覆写/删除。
- 控制台在对应记录专页显式点击核对，展示状态/受控字段名和时间。取消/离开/资源或空间变化后丢弃旧观察；不自动重试或执行修复。写操作继续使用原近期 MFA/精确 ETag/确认流程。
- 真实 MySQL/fake Admin 分别验证只读无副作用、缺失/一致/漂移、敏感上游字段不输出、初始无资格不发请求、RPC 中撤权/版本变化与取消；真实 Hydra/Bearer/BFF/浏览器验证相同范围，补齐 OpenAPI/Playground、文档、元数据截图与受影响回归。模拟协议故障不计作真实引擎证据。
